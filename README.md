#  JavaScript Stopwatch (MM:SS:ms)

A clean, responsive, high-precision Stopwatch application built using HTML5, CSS3, and JavaScript (ES6), formatted in **Minutes:Seconds:Milliseconds**.

##  Features

* **Sub-Second Precision:** Tracks time accurately down to milliseconds using `Date.now()`.
* **Minutes:Seconds:Milliseconds Format:** Displayed cleanly as `00:00:000`.
* **Smart Controls:** Start, Stop, and Reset buttons with active state management to prevent double-starting intervals.
